Live Demo GitHub

About the Project

A comprehensive restaurant management system built with Next.js 16, Supabase, and TypeScript. Features include menu browsing, shopping cart, order management, multiple payment methods (UPI, Card, Cash), live order tracking, table reservations, customer reviews, and a full admin panel with WebSocket-powered real-time order updates, audio alerts, menu CRUD operations, financial analytics dashboard, coupon management, reservation management, review moderation, and KPI tracking. Authentication via OTP and Google OAuth with role-based access control.

Next.js 16 Supabase TypeScript WebSocket Payments
