Case Study: EventPass

Building a full-stack event ticketing platform from concept to deployment

The Challenge

Event organizers face a unique set of challenges when selling tickets — managing inventory across multiple ticket tiers, applying promotional discounts, handling payments in different currencies, and generating post-event reports. Many existing platforms charge high fees or lack the flexibility that smaller event organizers need. The goal was to build a customizable ticketing platform that gives organizers full control over their events, pricing, and customer data.

The system needed to support an admin-mediated approval flow where organizers review and approve orders before payment processing, preventing fraudulent transactions and ensuring accurate capacity management. Additionally, multi-currency support was critical since events often attract international attendees.

The Approach

I began by analyzing the complete event ticketing lifecycle — event creation, ticket listing, customer browsing, checkout, payment, and post-event reporting. Each stage was broken down into user stories and technical requirements. Next.js 15 provided the full-stack framework with server components for fast page loads and API routes for secure backend operations.

Supabase handled authentication, real-time database updates, and file storage for event images. The coupon system was built with flexible discount rules — percentage-based or fixed amount — with expiration dates and usage limits. For multi-currency support, I integrated a currency conversion API and stored all prices in a base currency with exchange rate snapshots for accurate historical reporting.

PDF report generation was implemented using a server-side library that compiles order data, revenue summaries, and attendee lists into professionally formatted documents. OTP verification via Resend added an extra layer of security for customer accounts without the friction of password creation.

The combination of Next.js server components and Supabase real-time subscriptions creates a fast, responsive experience. PostgreSQL's robust querying powers the analytics dashboard, while Tailwind CSS ensures a polished, mobile-friendly interface. The app is deployed on Vercel with automated CI/CD via GitHub.

Key Features

  • Admin-Mediated Approval Flow: Orders are reviewed by organizers before payment processing, preventing fraud and overselling.
  • Promotional Coupon System: Percentage and fixed discounts with configurable expiration, usage limits, and minimum purchase requirements.
  • Multi-Currency Support: Automatic currency detection and conversion for international attendees with accurate reporting.
  • PDF Report Generation: Downloadable reports for orders, revenue, and attendee lists in professionally formatted PDFs.
  • Real-Time Analytics Dashboard: Revenue tracking, user behavior analysis, and sales trends with interactive charts.
  • OTP Authentication: Passwordless login via email OTP using Resend for secure, frictionless user access.

Results & Impact

EventPass successfully launched as a fully functional ticketing platform. Organizers gained full control over their event listing and ticket sales, with transparent pricing and no hidden fees. The admin-mediated approval flow reduced fraudulent orders to zero, and the coupon system helped organizers run targeted promotions that increased ticket sales by offering time-limited discounts.

The PDF report generation saved organizers hours of manual reporting work, and the multi-currency support opened up events to a global audience. The analytics dashboard provided actionable insights into sales patterns, popular ticket tiers, and customer demographics — helping organizers make data-driven decisions for future events.
