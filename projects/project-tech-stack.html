Technology Stack

The modern tools and frameworks I use to build applications

Next.js

Full-stack React framework with server-side rendering, static generation, API routes, and server components. Provides excellent performance, SEO, and developer experience out of the box.

React

Component-based UI library for building interactive user interfaces. I use hooks, context, and modern patterns to create reusable, maintainable components.

TypeScript

Type-safe superset of JavaScript that catches errors at compile time. Enables better tooling, documentation, and code maintainability in large codebases.

Supabase

Open-source Firebase alternative providing real-time databases, authentication, storage, and edge functions. Powers the backend for most of my projects with minimal overhead.

PostgreSQL

Powerful open-source relational database with advanced querying, indexing, and JSON support. Provides the reliability and performance needed for production applications.

Tailwind CSS

Utility-first CSS framework for rapid UI development. Enables consistent design systems with responsive layouts and dark mode support without leaving HTML.

Node.js

JavaScript runtime for server-side development. Used for API routes, serverless functions, and build tooling across all my projects.

Vercel

Platform for deploying frontend and serverless applications. Provides automatic SSL, CDN, preview deployments, and seamless Git integration.

GitHub

Version control and collaboration platform. Used for code hosting, pull requests, issue tracking, and CI/CD workflows with GitHub Actions.

How These Work Together

Next.js serves as the foundation, handling both frontend and backend logic. TypeScript ensures type safety across the entire codebase. Supabase and PostgreSQL manage data and real-time features. Tailwind CSS provides the visual layer. Vercel hosts the application with zero-config deployment, and GitHub manages version control and CI/CD. This stack enables rapid development without sacrificing quality or scalability.
