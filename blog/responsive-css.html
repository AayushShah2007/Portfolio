Mastering Responsive CSS

Published: February 15, 2026 • 6 min read

Responsive design is no longer optional. With users accessing the web from phones, tablets, laptops, and even smart displays, your layouts must adapt seamlessly across every viewport. The modern CSS toolkit — Grid, Flexbox, container queries, and clamp-based typography — gives us unprecedented control over responsive layouts without JavaScript. The key is adopting a mobile-first mindset and using progressive enhancement to layer in complexity for larger screens.

CSS Grid has revolutionized layout design. Instead of nesting flex containers, you define a grid template at the parent level and place children explicitly or automatically. I use the auto-fit and minmax() functions together to create responsive grids that require zero media queries: grid-template-columns: repeat(auto-fit, minmax(280px, 1fr)). This pattern automatically adjusts columns based on available space — on a phone you get one column, on a tablet two, on a desktop three or more. For more control, the subgrid feature lets child grids inherit row and column tracks from their parent, enabling perfectly aligned card layouts where images, titles, and CTAs line up regardless of content length.

Container queries are the most significant CSS advancement in years. Unlike media queries that respond to the viewport, container queries respond to the size of a parent container. This is game-changing for reusable components — a card component can query its container's width rather than making assumptions about its context. Using @container (min-width: 400px), you can switch from a stacked to a side-by-side layout based on the available space within a grid cell or sidebar. Combined with the cqw and cqi units, you can size typography and spacing relative to the container rather than the viewport, creating truly context-aware components. Browser support for container queries is now universal, so there's no reason not to adopt them.

Fluid typography using clamp() eliminates the need for breakpoint-specific font sizes. Instead of font-size: 1rem on mobile and 1.5rem on desktop, use font-size: clamp(1rem, 0.5rem + 2vw, 1.5rem). The browser interpolates the value smoothly across all viewport widths. I use a CSS custom property approach where each text style is defined with its own clamp value, making global typography changes trivially easy. For the portfolio site itself, I pair clamp() with container-type: inline-size on section containers to ensure hero text looks proportionate in both wide and narrow layouts. Responsive CSS is no longer about fighting the browser — it's about leveraging modern CSS features to build layouts that feel naturally adaptive.
