Experience & Timeline

My journey from a curious beginner to a full-stack developer building production applications

The Full Timeline

Every milestone that shaped my career

2022 — The Beginning

First Line of Code

Wrote my first "Hello, World" program in C. That single moment sparked a passion for programming that has never faded. I spent months learning the fundamentals — variables, loops, functions, pointers, and memory management. Built my first console applications including a calculator and a simple banking system.

2023 — Expanding Horizons

Mastering Multiple Languages

Moved from C to C++ where I discovered object-oriented programming. Learned C# and the .NET framework, building desktop applications with Windows Forms. This was also the year I discovered web development — HTML, CSS, and JavaScript opened up an entirely new world of creating visible, interactive applications. Built my first web pages and portfolio site.

2024 — Full Stack Breakthrough

Next.js & Supabase Ecosystem

Discovered the Next.js + Supabase ecosystem and it was a revelation. Built EAT O'CLOCK — a complete restaurant management system with real-time orders, payment integration, live tracking, reservations, and an admin KPI dashboard. This project taught me full-stack architecture, database design with PostgreSQL, authentication flows, and production deployment with Vercel.

2025 — Production Ready

Second Major Project & Client Work

Launched EventPass, a full-stack ticketing platform with coupon system, multi-currency support, admin analytics, PDF report generation, and OTP authentication. Started taking on freelance client projects, delivering custom web applications for small businesses. Refined my development workflow with Git, CI/CD, and agile practices.

2026 — Present Day

Ongoing Growth & New Challenges

Currently expanding my expertise in system design, cloud architecture, and advanced Next.js patterns. Taking on more complex client projects and exploring new technologies. Building this portfolio to showcase my journey and connect with potential clients and collaborators. Always learning, always building.
